# Essência Beauty Hub

Prompt para Lovable — Site do Espaço Essência

Crie um site completo, moderno, elegante, responsivo e altamente otimizado para SEO local para o Espaço Essência, um salão de beleza em Alvorada/RS.

Objetivo do projeto

O site deve transmitir uma imagem de sofisticação, confiança, feminilidade e alto padrão, com foco em:

gerar agendamentos pelo WhatsApp;

posicionar o salão organicamente no Google para buscas locais;

apresentar claramente os serviços de cabelo e unhas;

valorizar o visual premium da marca;

converter visitantes em leads.

Estilo visual e identidade

Siga uma identidade visual com predominância de:

preto

dourado

branco ou tons neutros como apoio

Direção estética:

visual premium e refinado;

elegante, feminino e moderno;

aparência de salão de beleza sofisticado;

interface limpa;

tipografia de bom gosto;

detalhes dourados sutis em botões, ícones, divisórias ou títulos;

evitar visual exagerado ou poluído.

Diretrizes de mídia

Cabelos

Nas páginas de cabelo, usar as mídias reais que eu vou enviar para o projeto.

Unhas

Nas páginas de unhas, você pode gerar imagens realistas e sofisticadas, coerentes com o visual do site, incluindo:

mãos bem cuidadas;

unhas tradicionais com esmaltação elegante;

alongamentos de unhas com acabamento premium;

fotos limpas, bonitas e com aparência profissional.
